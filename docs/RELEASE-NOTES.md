# Orion — release notes

## 1.000 — 16 November 2026

First release.

### Contents

- Variable font with four axes: `wght` 100–900, `wdth` 75–125, `opsz` 10–72, `GRAD` −50…+100; 27 named instances.
- 899 glyphs, 774 characters: Latin including Vietnamese, monotonic Greek and Cyrillic (41 tested languages in all),
  punctuation, 19 currency signs, mathematical operators, arrows and interface symbols.
- Static families Orion, Orion Display and Orion Condensed in nine weights (TTF, autohinted), Orion in OTF, WOFF2 for everything,
  six `unicode-range` subsets of the variable font.
- OpenType: kerning, mark and mark-to-mark positioning, composition, localised forms, capital punctuation, contextual colon,
  tabular and proportional figures, slashed zero, fractions, small figures, ordinals, three stylistic sets.
- Type presets for TV, desktop, tablet and phone, with generated CSS, React, Jetpack Compose, Android XML, Swift and Roku files.
- Editable sources: parametric generator, 21 UFO masters, designspace, feature file, build script.
- QA suite: 1,022 passing checks, 8 warnings, no failures; FontBakery universal profile with no failures.
- 23 specimens rendered from the shipped variable font, with their HTML sources.

### Known limitations

Design

- **Not reviewed by a type designer.** The outlines are generated by code and were checked by automated tests and by looking at
  rendered proofs during development. A professional review of curve quality, spacing rhythm and the extremes of the designspace
  is recommended before a public or brand-critical release.
- **Heaviest weights of `S s 3 5 §`** have small apertures; they are legible at display sizes but are the least refined shapes
  in the family, most visibly in Black Condensed.
- **`rn` against `m`** is separated less well than in Inter under simulated blur (see ACCESSIBILITY.md).
- **Optical size and grade away from normal width** are computed from deltas rather than drawn; they pass the topology tests
  but have had less visual review.
- **No italic or slant axis.** Emphasis has to come from weight, grade or colour, or from a synthesised oblique, which is not
  recommended.
- **No `avar`.** Named weights are evenly spaced in stem thickness between the masters at 100, 400 and 900, not perceptually tuned.
- **No ligatures**, by decision.

Coverage

- Greek is monotonic only; Cyrillic stops at U+045F plus `Ґ ґ`; there are no Bulgarian localised forms and no Polish kreska.
- No Arabic, Hebrew, Indic, Thai, CJK or Korean. UNICODE-COVERAGE.md gives a fallback stack.
- The symbol set is an interface subset; there are no emoji.

Engineering

- The variable font is unhinted. Static TrueType files are autohinted in the vertical direction only; there is no manual
  hinting and no ClearType-specific tuning. Static OTF files are unhinted.
- The variable TrueType file keeps overlapping contours.
- Six Vietnamese capitals leave sub-pixel fragments when overlaps are removed at some instances; static builds drop them.
- Light closes some counters below 13 px per em and Black below 18 (FreeType greyscale).

Testing

- **No physical device was used.** Rendering was verified in Chromium, FreeType and HarfBuzz only. Apple platforms, Windows,
  Tizen, webOS, Roku, Fire TV and real panels are untested; QA-REPORT.md section D lists the evidence per platform.
- Legibility results are software simulations; there was no user testing.

Name and rights

- **“Orion” is already used as a typeface name by other foundries** (for example Linotype's Orion, designed by Hermann Zapf, and
  several later families). No trademark search or clearance was performed. Choose and clear a different name before distributing
  the fonts publicly or commercially. The family name is set by `FAMILY` in `sources/build-scripts/orion/params.py` and by the file-name constants at the top of
  `sources/build-scripts/build.py`.
- The vendor ID `ORIN` is a placeholder.
- See LICENSE.md for the licence and provenance statement.

### Suggested next steps

1. Device pass: one television per platform and tier, using `specimens/html/`.
2. Type-design review of Black, Thin and the Condensed extremes; manual correction of `S`, `a`, `e`, `g` in the UFO masters or the generator.
3. Decide the final name; then regenerate.
4. If Windows desktop is a target, commission TrueType hinting for the Regular and Bold statics.
5. Italic or slant axis; Bulgarian forms; polytonic Greek; extended Cyrillic, in that order of likely value for a streaming catalogue.
