# Orion

A variable sans-serif family for streaming interfaces on television, desktop, tablet and phone. Version 1.000.

Orion is geometric in skeleton and humanist in its corrections: round bowls and even strokes for a cinematic, modern voice;
a tall x-height, open apertures and differentiated `I l 1 0 O` for reading metadata from the sofa. One file covers Thin to
Black, Condensed to Extended, caption to display optical sizes, and a grade axis that changes weight without changing width.

> **Read first.** Orion was generated by a parametric program and verified with software tests only. It has not been reviewed
> by a professional type designer and has not been tested on a physical television. The name “Orion” is not cleared for use.
> RELEASE-NOTES.md lists every known limitation.

## Quick start

| I want to… | Use |
|---|---|
| Look at the font | `specimens/` (PNG) or open `specimens/html/tester.html` in a browser for live sliders |
| Use it on the web, Tizen or webOS | `integration/css/orion.css` with `fonts/variable/Orion-VF.woff2` and the static fallback in `fonts/webfonts/` |
| Use it on Android, Android TV, Fire TV | `integration/android/` with `fonts/variable/Orion-VF.ttf` |
| Use it on iOS, iPadOS, tvOS | `integration/ios/OrionFont.swift` with `fonts/variable/Orion-VF.ttf` |
| Use it on Roku | `integration/tv-platforms/roku/` with `fonts/static/` |
| Install it on a computer | `fonts/static-otf/` (design tools) or `fonts/static/Orion/` |
| Change the design | `sources/build-scripts/README.md` |
| Check the evidence | `docs/QA-REPORT.md`, then `python3 qa/run_all.py` |

## Rebuilding

```bash
pip install -r sources/build-scripts/requirements.txt
python3 sources/build-scripts/build.py all      # about 2.5 minutes
python3 qa/run_all.py                           # about 8 minutes
python3 specimens/src/build_specimens.py        # needs Chrome or Chromium
python3 integration/tokens/build_tokens.py      # after editing the type presets
```

A clean rebuild reproduces the shipped variable font table for table (only `head`, which carries the timestamp, differs).
