# Contributing to Orion

Thank you for helping. The most useful contributions right now:

1. **Device reports.** Install the fonts or open `specimens/html/` on a real TV, phone or desktop and tell us what you see: platform, model year, OS version, a photo or screenshot, and which sizes and weights look wrong.
2. **Glyph and spacing fixes.** Orion's outlines are generated by `sources/build-scripts/orion/`. Fix the generator rather than a single master, so every weight and width gets the correction. `sources/build-scripts/README.md` explains the layout.
3. **Language coverage.** Add the characters to `orion/charset.py`, draw any new base shapes, and add the language to `qa/qa_unicode.py`.

## Before opening a pull request

```bash
pip install -r sources/build-scripts/requirements.txt
python3 sources/build-scripts/build.py all
python3 qa/run_all.py
```

- The QA run must finish with no failures. New warnings need an explanation in the pull request.
- Commit the regenerated `sources/masters`, `fonts` and `qa/reports` together with the generator change.
- Do not add outlines, kerning or feature code taken from other typefaces. Measurements are fine; copied data is not.
